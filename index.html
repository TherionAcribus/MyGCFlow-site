Version alpha · Windows

Vos trouvailles de géocaching, rejouées sur une carte.

MyGCFlow lit votre Pocket Query « My Finds » et fait réapparaître vos caches jour après jour, dans le style de carte de votre choix. Vous pouvez ensuite enregistrer l'animation en vidéo.

Télécharger pour Windows Code source sur GitHub

Gratuit. Un petit projet personnel, encore en rodage.

Le principe

  1. 1

    Chargez vos trouvailles

    Exportez la Pocket Query « My Finds » depuis geocaching.com, puis chargez le fichier .gpx ou .zip. Filtrez par type de cache, par période ou par pays.

  2. 2

    Composez la carte

    Fond de carte, forme et couleur des points, effet d'apparition, titre et compteur. Enregistrez vos réglages dans un profil pour les retrouver.

  3. 3

    Rejouez et enregistrez

    Choisissez la période et le rythme, ajoutez une musique si vous le souhaitez, puis enregistrez la vidéo.

Vos données restent sur votre ordinateur. L'application tourne en local et s'ouvre dans votre navigateur ; seules les tuiles du fond de carte viennent d'Internet.

Un projet en version alpha

MyGCFlow fonctionne, mais il est jeune : la version actuelle est la 0.0.2. Attendez-vous à des bugs, à des réglages qui changent d'une version à l'autre et à une interface encore en rodage.

  • Windows uniquement pour l'instant.
  • L'application n'est pas encore signée : au premier lancement, Windows SmartScreen affiche un avertissement.
  • Les retours sont les bienvenus, via les tickets GitHub.
